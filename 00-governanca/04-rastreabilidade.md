# Matriz de rastreabilidade e IDs

## Nomenclatura
- `CHR-<SLUG>` personagem; `LVL-01...10` cenário; `M01...M10` missão; `SC-01...11` cena; `SYS-*` sistema; `QA-*` teste; `ADR-*` decisão técnica.

## Fluxo
Premissa → beats → capítulos → quests → sistemas → testes → release gates. Toda linha relevante no Kanban referencia ao menos um identificador. Cada NPC possui tabela de flags; nenhuma decisão narrativa deve existir somente na câmera.
