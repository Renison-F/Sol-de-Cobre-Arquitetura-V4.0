# Estimativas V3 e caminho crítico

Base: 157 tarefas, 7712 horas-pessoa, reserva inicial 30%. Fonte detalhada `11-contratos/backlog.json`. Não inclui encargos de contratação, impostos, loja, nuvem, marketing e operação recorrente. Valor/hora é insumo do proprietário, não foi presumido.

Caminho de gameplay: bootstrap → input → motor → laço → slice → troca de herói → demais sistemas → capítulos → campanha QA. Caminho comercial: sandbox/KMS → principal → adaptadores Android/iOS → verificador interoperável → fluxo de restauração → pentest/release. Caminho artístico: escala/feel → vistas técnicas → malha/UV → rig/clips → prefab → ambiente → QA.

O maior desses caminhos, limitado pela capacidade das funções, define prazo. Dividir horas totais pelo número de pessoas não considera especialização, dependências ou revisões. Reestimar após M2 com produtividade observada e volume de retrabalho, sem converter números preliminares em promessa.
