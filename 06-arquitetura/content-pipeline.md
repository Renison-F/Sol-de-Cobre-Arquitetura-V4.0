# Pipeline de conteúdo e validação

Fonte autoral em Markdown/YAML no repositório; exportador gera ScriptableObjects e JSON de referência versionado. IDs de diálogo, missão, NPC e cena passam por linter; nenhuma quest referencia capítulo inexistente.

Pipeline de arte: concept aprovado → turnaround → sculpt/blockout → retopo/UV → bake e texturas → rig → animações → prefab → perf/QA. Uma imagem renderizada não é modelo 3D. Identidade visual é verificada por paleta e silhouette sheet.
